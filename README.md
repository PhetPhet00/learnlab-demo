# LearnLab — Thai Learning App Demo

เว็บแอปตัวอย่างสำหรับเรียนรู้หลายวิชา มีคลิปวิดีโอ แบบทดสอบ คะแนน และการติดตามความคืบหน้า ใช้ Python standard library เป็นเว็บเซิร์ฟเวอร์และ SQLite เป็นฐานข้อมูล

## Features

- Dashboard และรายวิชาตัวอย่าง: คณิตศาสตร์ ภาษาอังกฤษ และวิทยาศาสตร์
- คลิปวิดีโอประกอบบทเรียน (YouTube embed)
- แบบทดสอบตัวอย่าง ตรวจคะแนนอัตโนมัติ
- ประเมินระดับเบื้องต้น: เริ่มต้น / กลาง / สูง
- บันทึกโปรไฟล์ ความคืบหน้ารายวิชา บทเรียน และประวัติคะแนน
- SQLite database สร้างอัตโนมัติเมื่อเริ่มเซิร์ฟเวอร์
- Responsive layout สำหรับหน้าจอคอมพิวเตอร์และมือถือ
- สลับธีมได้ 2 แบบ: สว่าง (ธีมเดิม) และมืดโทนดำ-เขียว โดยจดจำตัวเลือกในเบราว์เซอร์
- เปลี่ยนโลโก้แอปและ favicon เป็นรูปหนังสือ

## Requirements

- Python 3.9 หรือใหม่กว่า (แนะนำ Python 3.11+)
- เว็บเบราว์เซอร์สมัยใหม่
- ไม่ต้องติดตั้งแพ็กเกจผ่าน `pip`

## Run locally on Windows

1. Download หรือ clone repository นี้
2. ติดตั้ง Python จาก <https://www.python.org/downloads/> หากยังไม่มี
3. เปิดโฟลเดอร์โปรเจกต์
4. ดับเบิลคลิก `start.bat` หรือเปิด Terminal แล้วรัน:

```bash
python app.py
```

5. เปิด <http://127.0.0.1:8000>
6. ปล่อยหน้าต่าง Terminal เปิดอยู่ขณะใช้งาน

## Run on macOS / Linux

```bash
python3 app.py
```

จากนั้นเปิด <http://127.0.0.1:8000>

## API endpoints

- `GET /api/health` — ตรวจสอบสถานะเซิร์ฟเวอร์และฐานข้อมูล
- `GET /api/state?client_id=...` — โหลดข้อมูลเดโม่ของเบราว์เซอร์
- `POST /api/state` — บันทึกสถานะการเรียน

ฐานข้อมูลชื่อ `learnlab.db` จะถูกสร้างไว้ในโฟลเดอร์โปรเจกต์เมื่อเริ่มเซิร์ฟเวอร์ครั้งแรก ไฟล์ฐานข้อมูลถูกระบุใน `.gitignore` จึงไม่ถูกอัปโหลดขึ้น GitHub โดยปกติ

## Security and data notes

- This is a learning/demo project, not production-ready.
- ยังไม่มีระบบสมัครสมาชิก/เข้าสู่ระบบจริง ข้อมูลเดโม่ถูกแยกด้วย client ID ในเบราว์เซอร์ ไม่ใช่การยืนยันตัวตนที่ปลอดภัย
- อย่าใช้เก็บข้อมูลส่วนบุคคลจริงของนักเรียนก่อนเพิ่ม authentication, authorization, HTTPS, backup, rate limiting และมาตรการตาม PDPA
- วิดีโอเป็นตัวอย่างภายนอก การแสดงผลขึ้นกับการตั้งค่าการฝังวิดีโอและเครือข่าย
